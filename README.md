# Global Agent Configuration

This repository stores global skill files and the agent configuration used by
Codex.

## Directory Structure

- `AGENTS.md`: Global instructions used by Codex agents.
- `skills/`: Global skill files available to agents.
- `.skill-lock.json`: Local skill installation state generated by skill
  management tooling. This file is ignored by Git.

## Skills

- `caveman`: Ultra-compressed response mode for reducing token usage.
- `diagnose`: Structured debugging loop for bugs and performance regressions.
- `find-skills`: Discover and install additional agent skills.
- `grill-with-docs`: Stress-test plans against project language and ADRs.
- `improve-codebase-architecture`: Find architecture and refactoring
  opportunities that improve module depth, locality, and testability.
- `tdd`: Guide test-first work with a red-green-refactor loop.
- `write-a-skill`: Create or update Codex skills using current skill structure
  and validation practices.
- `zoom-out`: Explain unfamiliar code from a higher-level module and caller map.

## Usage

After cloning this repository on a server, link Codex's global
`~/.codex/AGENTS.md` file to the `AGENTS.md` file in this repository.

Run the following commands from the repository root:

```sh
mkdir -p ~/.codex
ln -sf "$(pwd)/AGENTS.md" ~/.codex/AGENTS.md
```
